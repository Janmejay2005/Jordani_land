# 🏃 Jordani Land Portfolio

An experimental portfolio website for **Janmejay Kumar Singh**, designed as an interactive endless-runner / game-inspired experience.

## Files

```text
jordani-land-portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    └── janmejay-profile.png
```

## Features

- Game-style opening screen: **Welcome to Jordani Land**
- Subway-runner inspired CSS environment without external game assets
- Personal profile and leadership section
- Skills and technology districts
- Project mission map with filters
- Interactive client-side AI demo
- RAG / parsing / embeddings learning pipeline visualization
- Clickable collectible coins + XP HUD
- Responsive layout
- Separate HTML, CSS and JavaScript files
- Uses the uploaded profile image locally

## Run locally

Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.

## Important

The "AI Core" is a **frontend demo intent engine**, not a real LLM. To turn it into a production AI assistant, connect the form to your backend/API and keep API keys on the server.

The visual direction is inspired by the energy of an endless subway runner, but this demo does not use Subway Surfers assets.
